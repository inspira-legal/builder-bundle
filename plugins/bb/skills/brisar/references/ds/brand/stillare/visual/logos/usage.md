# Stillare — Logo usage

Two assets, both vector, both built on the brand palette: **Slate Gray `#6f7a93`** + **Cornflower `#6a96ea`**. The logo files are the canonical proof of the color direction — the wordmark is Slate, the droplet pairs Slate + Cornflower.

| File                | What it is                                                     | Use for                                                 |
| ------------------- | -------------------------------------------------------------- | ------------------------------------------------------- |
| `stillare-logo.svg` | Full lockup — droplet + "stillare" wordmark (viewBox 1920×524) | Headers, marketing, docs, anywhere with horizontal room |
| `stillare-iso.svg`  | Isotype — the distillation droplet alone (viewBox 1080×1080)   | App favicon, sidebar mark, avatars, tight/square spaces |

## The droplet is the brand's verb

The isotype is a **droplet mid-distillation**: a Cornflower drop (`.cls-2`) with a smaller Slate drop (`.cls-1`) condensing beneath it — excess becoming essence. It's the same metaphor the product runs on. Treat it as earned (see DESIGN.md → Craft & Taste #6): use it where distillation literally happens (logo, the "destilado" chip, the AI/assistant avatar), never as a generic bullet or decoration.

## Rules

- **Clear space:** keep padding ≥ the height of the droplet around the full lockup. Don't crowd it.
- **Minimum size:** wordmark ≥ 96px wide; isotype ≥ 20px. Below that, use the isotype, never the shrunk wordmark.
- **Color:** ship as-is (Slate + Cornflower) on light and on the gray canvas. On dark surfaces the two brand colors still read — verify, and only if needed swap the Slate parts (`.cls-1`) to `#cdd2db` for contrast. Never recolor the Cornflower droplet; it's the family thread.
- **Don't:** rotate, add effects/shadows, place on a busy photo, recolor to a single flat hue, or stretch (the SVG viewBox preserves ratio — scale, don't distort).

> These SVGs are the source of truth for the mark. Theme lockups (dedicated light/dark variants) are not yet cut — see DESIGN.md → Open Questions.
