# Confidence & steelman: shared reasoning protocols

The reasoning skills (`/bb:think`, `/bb:challenge`) close and open the same way.
This file owns both protocols; the skills link here instead of restating them.

## Steelman first

Before evaluating or challenging a position, reformulate it as the **strongest
possible version** of the argument, stronger than the user stated it. Confirm:
_"Is that a fair reading, or would you adjust something?"_ If the position is
vague, ask
one clarifying question before proceeding; never fabricate a thesis. The
steelman always comes before any critique.

## Confidence assessment: the close

Every session ends with an explicit confidence level:

- **HIGH**: solid position, challenges addressed
- **MEDIUM**: manageable risks, premises to monitor
- **LOW**: central premise untested, real risk of failure
- **PIVOT**: the question or thesis itself is poorly framed; recommend
  revisiting before acting

If MEDIUM or LOW: name the riskiest premise and suggest the smallest experiment
to test it.
